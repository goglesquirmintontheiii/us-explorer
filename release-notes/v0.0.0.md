First build: Phase 0 (foundations), plus an early look at Phase 1 terrain.

**What's in it**

- A full-scale WGS84 globe with real terrain (USGS 3DEP lidar where available) and Esri or USGS imagery, streamed around you
- Physically based sky with the real sun position for your time and place
- Free-flying camera: right mouse or Tab to look, WASD, Space/Ctrl, Shift, mouse wheel for speed
- T: go to any place by name, address or coordinates
- Esc menu: settings (graphics preset, imagery source, units, download cap, cache size and folder), offline area download, credits, update check
- F3 info overlay: frame rate, position, tiles, video memory estimate, network, cache, weather service
- One-click updates from GitHub releases (AppImage)

**Run it**

```sh
chmod +x US_Explorer-0.0.0-x86_64.AppImage
./US_Explorer-0.0.0-x86_64.AppImage
```

Settings live in `~/.config/us-explorer/settings.toml`; the tile cache in `~/.cache/us-explorer`.
